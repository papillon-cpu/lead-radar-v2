# Авито-сканер заказов (v1.0)

Расширение для Chrome и Яндекс.Браузера: собирает заказы со страницы Авито, оценивает их
(подходит ли под ваши услуги, какая именно нужна, какой бюджет) и заливает их в **лид-радар**
вместе с готовым черновиком ответа.

**Отклики самостоятельно не отправляются** — расширение только собирает и готовит текст.
Отправляете вы, руками. Так вы не отправите мусор заказчику.

## Что нужно

1. Запущенный лид-радар: `http://127.0.0.1:4000` (в его папке `npm start`).
2. Авито, где вы войли в свой рабочий аккаунт.

## Установка

1. Распакуйте архив в отдельную папку (например `D:\Projects\avito-scanner`).
2. Откройте `browser://extensions` (в Яндекс.Браузере) или `chrome://extensions` (в Chrome).
3. Включите «Режим разработчика» (в Яндексе — галочка слева вверху).
4. Нажмите «Загрузить распакованное расширение» и укажите папку с `manifest.json`.
5. Закрепите расширение на панели (значок «Авито-сканер»).

## Как пользоваться

1. Откройте раздел заказов: `https://www.avito.ru/moscow/zakazy` (город меняется в панели;
   есть кнопка «Предложения услуг» — там другая рубрика, тоже полезна).
2. Прокрутите страницу до конца — Авито подгружает заказы по мере скролла.
3. Нажмите значок расширения → **«Сканировать страницу»**.
4. В списке появятся найденные заказы: у каждого — бюджет, город, оценка («подходит» / «мимо»)
   и наша подходящая услуга. Черновик ответа — в поле под карточкой, кнопка **«Скопировать ответ»**.
5. **«Импортировать в лид-радар»** — заказы попадут в таблицу лидов (статус «Новый»), с городом,
   бюджетом и ссылкой на заказ. Дубли не импортируются дважды.

## Как это связано с лид-радаром

| Шаг | Что происходит |
|---|---|
| Скан | Расширение читает то, что уже показано на странице, и отправляет в `POST /api/avito/analyze` |
| Оценка | Сервер определяет услугу (лендинг, сайт, бот, автоматизация, AI, CRM…), отсеивает вакансии и быт |
| Черновик | Текст ответа собирается по вашему профилю из лид-радара (имя, офер, портфолио) |
| Импорт | `POST /api/import` — лид появляется в таблице, дальше аудит → лендинг → письма |

## Настройки

- Профиль (имя, офер, ссылка на портфолио) — в лид-радаре, раздел «Профиль».
- Если сервер на другом порту — поправьте `API` в начале `popup.js`.
