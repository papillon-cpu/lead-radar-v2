# Лид-радар v2

Облачный лид-радар для фриланс-подработки: заказы с Авито → оценка (правила + ИИ) → черновик ответа → лиды.

- Приложение: https://lead-radar.spru.run/
- Расширение «Авито-сканер v2» лежит в папке `avito-scanner/`.

Файлы обновляются автоматически из приложения (workflow `sync.yml`).
